> [!definition] Normal Random Variable
> $X$ is a normal variable, or $X$ is normally distributed with parameters $\mu + \sigma^{2}$, if the density of $X$ is given by:
> $$
> \begin{align}
> f(x) = \frac{1}{ \sqrt{ 2\pi } \sigma} e^{-\frac{(x-\mu)^{2}}{2 \sigma^{2} }}
> \end{align}
> $$
> Where $\mu$ is the mean, and $\sigma^{2}$ is the variance.

If $X$ is normal with parameters $\mu$ and $\sigma^{2}$, then $Z = \frac{X-\mu}{\sigma}$ will be normal with properties $\mu=0$ and $\sigma^{2} = 1$. Can be derived from the following proposition:

> [!proposition] 
> If $X$ is normally distributed with parameters $\mu$ and $\sigma^{2}$, then $Y = aX + b$ is normally distributed with parameters $\mu_{y} = a \mu + b$ and $\sigma_{y}^{2} = a^{2}\sigma^{2}$
^b8e4d6

`\begin{proof}`@[[5.4 Lecture - Normal random variables#^b8e4d6]]
Need to find PDF of $Y$. 1st, let's find the CDF:
$$
P(Y \leq t) = P(aX + b \leq t)
= P\left( X \leq \frac{t-b}{a} \right) = \boxed{ F_{x}\left( \frac{t-b}{a} \right) }
$$
So,
$$
\begin{align}
f_{y}(t) = \frac{d}{dt} F_{y}(t) = \frac{d}{dt} F_{x}\left( \frac{t-b}{a} \right)  \\
= F'_{x}\left( \frac{t-b}{a} \right) * \frac{d}{dt}\left( \frac{t-b}{a} \right) \\
\boxed{ = f_{x}\left( \frac{t-b}{a} \right) * \frac{1}{a} }
\end{align}
$$
Expanding gives
$$
\begin{align}
\frac{1}{a} * \left( \frac{1}{\sqrt{ 2\pi } \sigma} e^{-\frac{\left( \frac{t-b}{a}-\mu \right)^{2}}{2 \sigma^{2}} } \right) \\
\to \text{some algebra} \\
= \frac{1}{\sqrt{ 2\pi } (a \sigma)} e^{-\frac{(t-(a\mu+b))^{2}}{2 (a \sigma)^{2}}}
\end{align}
$$
So, $Y$ is normally distributed with parameters $a\mu + b$ and $a^{2}\sigma^{2}$.
`\end{proof}`
